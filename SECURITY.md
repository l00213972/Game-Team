## Game Updates and Bug Fixes

Game updates and bug fixes will generally be provided for the latest supported version

Updates may include:

- Fixes for gameplay bugs and glitches.
- Improvements to player controls and movement.
- Fixes for crashes and performance issues.
- Improvements to graphics, audio and animations.
- Balancing changes to gameplay mechanics.
- Fixes for issues with levels, missions and objectives.
- Improvements to the user interface and player experience.

Major gameplay changes and new features may be introduced in future versions of the game.

## Reporting a Bug or Issue
In order for bug reports to reach the development team, the preferred method is to use the issue sections of of the associated Github Repository

Provide as much details as possible to help us understand an issue and produce a solution
Details include: 
- The type of issue (gameplay, UI, statistics)
- Game version the game was run on
- The platform or game device used
- Step-by-step procedure to reproduce the issue
- Expected behaviour compared with what actually happened.
- Error messages displayed by the game
